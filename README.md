# Mother's Day - Prolog

Uma pequena coleção de programas e exercícios em Prolog.
Este repositório contém exemplos, resoluções e utilitários em Prolog (compatível com SWI‑Prolog) que demonstram conceitos como unificação, backtracking, regras e recursão, além de aplicações simples.
Link para o enunciado/teste: https://rachacuca.com.br/logica/problemas/dia-das-maes/
